# Document templates

## ADR Format

All Architecture Decision Records follow this structure:

```markdown
# ADR 000X: Title

## Status
Accepted | Proposed | Superseded by [ADR-XXXX](link)

## Context
Problem statement and key considerations.

## Decision
The decision made.

## Rationale
Why this decision was made.

## Consequences
Impacts and tradeoffs.
```

## README Format

Component documentation structure:

```markdown
# Component Name

Brief description of purpose.

## Prerequisites
- Tool/version requirements
- Configuration needs

## Quick Start
Setup and basic usage.

## Architecture/Structure
How it works internally.

## Configuration
Available options and examples.
```

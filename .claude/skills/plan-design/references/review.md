# Optional spec review brief

Use available runtime review capabilities only when requested or warranted. Provide the
spec path, requirements, authorization boundaries, and unresolved decisions. Ask the
reviewer to report material gaps, contradictions, scope additions and unusable acceptance
criteria with file/section evidence. Separate required corrections from suggestions.

The review is read-only. Do not modify files or lifecycle status. Report coverage and
limitations; a favorable verdict is evidence, not human implementation authorization.

A dual-pane file manager for the Omarchy terminal

Two panels, the F-key verbs and a command line, in the Total Commander tradition. manycommander wears your Omarchy theme and changes with it, opens archives and SFTP servers as panels, and previews images in the terminal. On ext4, btrfs and xfs, its copies and moves never leave a half-written file behind.

find and rename

Alt+F7 searches names and contents on a parallel walk and opens the results in a tab you can copy, move or trash from. Ctrl+F filters a panel as you type, Ctrl+D jumps to bookmarks and frequent directories, and Ctrl+M renames many files from a mask with a live preview and undo.

Find, filter, jump and rename

archives

Enter opens a zip, tar, .pkg.tar.zst or 7z archive as a read-only directory. You browse it with the usual keys, view its members, and extract them with F5. Nothing ever writes into an archive.

Browse and extract archives

quick view

Ctrl+Q turns the other panel into a quick view of the entry under the cursor. Pictures show as images, through Kitty graphics, Sixel or halfblocks, whichever your terminal speaks. Everything else gets an info card.

What the quick view shows

sftp

cd sftp://host/path browses a server through your own ssh, with your config, keys, agent and ProxyJump. F5 uploads and downloads. An upload never shows a partial file on a server with hard links; a server without them gets direct writes, and after a lost connection the report names the file that may be partial.

safe copy and move

On a local disk, a copy is written under a temporary name and renamed into place, so a file you can see is always complete. An overwrite replaces the old file atomically, never by truncating it. A move across filesystems deletes a source only after its copy is flushed to disk, so a crash can leave a file in both places, never in neither. A filesystem with neither hard links nor RENAME_NOREPLACE, such as some FUSE mounts, gets direct writes instead.

What each operation guarantees

trash

F8 moves to the freedesktop.org trash, the same one Nautilus and gio use, so you can restore from either. It never copies across filesystems. Deleting for good is Shift+F8, and it waits until you type delete.

Durability after a crash

live theme

manycommander reads the active Omarchy palette and watches for a switch. Pick a theme in the Omarchy menu and a running manycommander recolours within a fraction of a second. There is no hook to install and nothing to configure; light themes work as they are.

How theming works

set up in three steps

  1. Install the latest release with mise, which Omarchy ships. It needs Linux 6.8 or later on x86-64; mise checks the download against its checksum, and omarchy update keeps it current.

    {{ config.extra.install_mise }}

    Without mise, install a release by hand, or build it from source with a Rust toolchain.

  2. Bind it in ~/.config/hypr/bindings.lua. focus = true brings a running window forward instead of opening a second one.

    o.bind("SUPER + E", "File manager (dual pane)", { tui = "manycommander", focus = true })

  3. Press Super+E. The left panel opens in the working directory and the right one in your home; after that, every start restores your last tabs.

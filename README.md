# manycommander

Dual-pane terminal file manager for [Omarchy](https://omarchy.org/), in the Total Commander /
Midnight Commander tradition. Keyboard-driven, and themed live from the active Omarchy palette
(`~/.local/state/omarchy/current/theme/colors.toml`).

Status: design phase. Planned stack: Rust + ratatui.
